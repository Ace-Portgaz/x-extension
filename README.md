# Web Resource Sniffer

一个用于 Chrome / Edge 的 Manifest V3 扩展。它记录当前网页实际加载过的公开图片、完整视频候选和流媒体清单地址，适合调试网页或保存你有权下载的内容。音频和不可独立播放的视频分片会被忽略。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，然后选择本目录。
4. 打开目标网页并刷新，滚动到目标内容；视频需要先点击播放。
5. 点击扩展图标查看捕获结果。

## X.com 使用提示

- 图片一般来自 `pbs.twimg.com`，可直接预览和下载。
- 视频一般来自 `video.twimg.com`；扩展会优先显示页面提供的海报图，否则尝试读取直链视频首帧。
- 下载视频前会检查 MP4/WebM 文件签名，避免把媒体分片或错误页面保存为视频。
- `.m3u8` / `.mpd` 是流媒体清单，不是完整视频文件。本扩展只允许复制其地址。
- 临时签名链接可能过期；请在资源仍能正常播放时使用。

## 边界

本工具不会解密 DRM 内容，不会绕过登录、付费墙、来源权限或其他访问控制。请仅下载你拥有、已获授权或平台条款允许保存的内容。
