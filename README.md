# Stream Sniffer

用于 Chrome / Edge 的 Manifest V3 流媒体嗅探扩展。它只记录网页实际加载的 HLS (`.m3u8`) 和 DASH (`.mpd`) 清单，不再捕获普通图片、视频直链或音频文件。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开或刷新目标网页，并播放目标视频。
5. 点击扩展图标查看捕获到的流媒体清单。

## 缩略图

扩展读取页面 `<video>` 元素提供的 `poster`，按页面顺序为捕获的流媒体显示缩略图。网站未提供公开海报图时会显示 HLS/DASH 占位图。

## 下载支持

- HLS 点播：支持无加密、非字节范围的 `.m3u8`，自动选择最高码率变体并合并媒体分片。
- HLS 直播：暂不下载，因为播放列表仍在持续变化。
- DASH：目前支持嗅探和复制清单链接，暂不进行音视频轨道合并。
- 加密流：不会解密，也不会绕过 DRM 或访问控制。
- 浏览器内存合并上限为 1 GB；较大的内容建议交给专业媒体工具处理。

## X.com 提示

刷新 X.com 后播放目标视频，再打开扩展。X 可能按滚动和播放状态动态加载清单；临时签名链接过期后需要重新捕获。

请仅保存你拥有、已获授权或平台条款允许下载的内容。
